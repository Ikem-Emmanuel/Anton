## Audit Methodology

1. Crawlability: robots.txt, meta robots, canonical tags, redirect chains
2. Indexation: sitemap.xml, Search Console coverage
3. Core Web Vitals: LCP (<2.5s), INP (<200ms), CLS (<0.1)
4. Structured data: JSON-LD validation against schema.org

## Priority Scoring

- Critical: CWV failures, crawl errors, security — fix within 24h
- High: Indexation, broken links, missing structured data — 1 week
- Medium: Content optimization, internal linking — 2 weeks
- Low: Nice-to-have — backlog
